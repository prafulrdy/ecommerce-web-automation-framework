# LinkedIn Project Description

Built an end-to-end E-Commerce Web Automation Framework using Java, Selenium WebDriver, TestNG, Maven, Page Object Model, GitHub Actions, and Jenkins.

Automated login, product sorting, cart, and checkout flows. Designed reusable page objects and framework components and added headless CI execution for regression testing.

Skills: Selenium WebDriver, Java, TestNG, Maven, Page Object Model, UI Automation, Regression Testing, GitHub Actions, Jenkins, CI/CD.
